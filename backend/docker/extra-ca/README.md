# شهادات CA إضافية

ضع هنا ملفّات `.crt` (بصيغة PEM) لأيّ سلطة تصديق داخلية — عادةً
عندما تكون الشبكة خلف بوّابة تفحص TLS، فتوقّع الشهادات بنفسها ويرفضها
`apt` و`pip` داخل الحاوية بـ`certificate verify failed`.

الملفّات هنا تُنسخ إلى `/usr/local/share/ca-certificates/extra/` ويُشغَّل
`update-ca-certificates` عليها أثناء البناء. المجلّد فارغ افتراضيًا، ولا
حاجة إليه على شبكة عادية.
